This is a new project. It will be the codebase repository for a MacOS clipboard manager. This app will help engineers and powerusers transform and modify clipboard content after it is copied and before it is pasted. This app will always run in the background in MacOS to ensure that content being pasted into all applications runs reliably. For example: some apps ignore the built-in plain-text "Cmd + Shift + V" feature and do their own thing. This service will ensure they do not ignore the shortcut because it will transform clipboard content before it is sent to the app. This will also add many other useful functions to help encode/decode/format/process/filter clipboard content.
